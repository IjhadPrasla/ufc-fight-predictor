# UFC Fight Predictor

Predicts the winner of a hypothetical UFC matchup based on historical
fighter stats (win/loss record, reach, striking/takedown averages, etc.)

## Project structure
```
ufc-predictor/
├── data/
│   ├── raw/                  <- put the downloaded Kaggle CSV here
│   └── fighter_stats.csv     <- generated by build_fighter_stats.py
├── model/
│   ├── train_model.py        <- trains + saves the classifier
│   ├── build_fighter_stats.py <- builds the per-fighter lookup table
│   └── trained_model.joblib  <- generated after training
├── backend/
│   └── app/main.py           <- FastAPI serving /predict and /fighters
└── frontend/                 <- React app (not built yet)
```

## Setup (do this once you have the dataset)

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

1. Download a UFC fight-stats dataset from Kaggle, put the CSV in `data/raw/`.
2. **Update the placeholder column names** in `model/train_model.py`
   (`RAW_STAT_PAIRS`) and `model/build_fighter_stats.py` to match the
   real dataset's columns.
3. Build the fighter lookup table:
   ```bash
   python model/build_fighter_stats.py
   ```
4. Train the model:
   ```bash
   python model/train_model.py
   ```
5. Run the API:
   ```bash
   uvicorn backend.app.main:app --reload --app-dir .
   ```
   Then test it at `http://localhost:8000/docs` (FastAPI's built-in
   interactive API explorer).
