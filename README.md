# UFC Fight Predictor

Predicts the winner of a hypothetical UFC matchup based on historical
fighter stats (height, reach, striking/takedown averages, age, etc.)

## Live Demo
🔗 [Try it here](https://ufc-fight-predictor-eight.vercel.app/)

Note: the backend is hosted on Render's free tier, which spins down after
15 minutes of inactivity — the first prediction after idle time may take
30-60 seconds while it wakes back up.

## Project structure

```
ufc-predictor/
├── data/
│   ├── raw/                  <- Kaggle dataset CSVs (not committed)
│   └── fighter_stats.csv     <- per-fighter lookup table, generated by build_fighter_stats.py
├── model/
│   ├── train_model.py        <- trains + saves the classifier
│   ├── build_fighter_stats.py <- builds the per-fighter lookup table
│   └── trained_model.joblib  <- trained model artifact
├── backend/
│   └── app/main.py           <- FastAPI serving /predict and /fighters
└── frontend/                 <- React + Vite app
```

## How it works
- **Data**: UFC historical fight and fighter data from Kaggle
  (`neelagiriaditya/ufc-datasets-1994-2025`).
- **Features**: only pre-fight known attributes (height, weight, reach,
  striking/grappling averages, age) — deliberately excludes in-fight
  stats to avoid data leakage.
- **Model**: logistic regression, chosen over a random forest after
  comparison. 68.2% accuracy, 0.723 AUC on held-out test data.
- **Backend**: FastAPI serving fighter lookups and win-probability predictions.
- **Frontend**: React + Vite, styled as a fight-card matchup screen.

## Running it locally

### Backend
```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

1. Download the Kaggle dataset above, place the CSVs in `data/raw/`.
2. Build the fighter lookup table:
```bash
   python model/build_fighter_stats.py
```
3. Train the model:
```bash
   python model/train_model.py
```
4. Run the API:
```bash
   uvicorn backend.app.main:app --reload
```
   Test it at `http://localhost:8000/docs`.

### Frontend
```bash
cd frontend
npm install
npm run dev
```
Open the printed local URL (usually `http://localhost:5173`).

## Known limitations
- No weight-class filtering — the model will predict any matchup, even
  across weight classes it rarely saw in training data. The UI shows a
  caveat when the weight gap is large.
- Render free tier cold-starts after inactivity (see Live Demo note above).
